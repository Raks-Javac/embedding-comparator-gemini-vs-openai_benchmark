# Embedding Comparator: Gemini vs OpenAI

**A production-ready FastAPI service for benchmarking and comparing semantic search performance between Google Gemini and OpenAI embeddings using Pinecone.**

This repository provides a robust benchmarking tool to compare vector embeddings generated by **Google Gemini** (`text-embedding-004`) and **OpenAI** (`text-embedding-3-large`). It utilizes **Pinecone** as a vector database to store and retrieve embeddings, allowing for semantic search and similarity analysis.

The project is built with **FastAPI** and is Docker-ready for easy deployment on platforms like Render.

## Features

- **Multi-Model Support**: Seamlessly switch between OpenAI and Gemini embedding models.
- **Semantic Search**: Vectorize queries and search for semantically similar text in your Pinecone index.
- **Pinecone Integration**: Automatic index creation and vector upsertion using the latest Pinecone SDK.
- **FastAPI Backend**: Clean, RESTful API documentation via Swagger UI.
- **Dockerized**: Containerized application for consistent development and deployment.

## Prerequisites

- **Python 3.10+**
- **Docker** (optional, for containerization)
- **API Keys**:
    - **OpenAI API Key**: For `text-embedding-3-large`
    - **Gemini API Key**: For `text-embedding-004` (Google GenAI)
    - **Pinecone API Key**: For Vector Database

## Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Raks-Javac/embedding-comparator-gemini-vs-openai_benchmark.git
   cd embedding-comparator-gemini-vs-openai_benchmark
   ```

2. **Create a virtual environment:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Environment Setup:**
   Create a `.env` file from the example:
   ```bash
   cp .env.example .env
   ```
   Populate `.env` with your API keys:
   ```env
   OPENAI_API_KEY=your_openai_key
   GEMINI_API_KEY=your_gemini_key
   PINECONE_API_KEY=your_pinecone_key
   PINECONE_INDEX_NAME=embedding-benchmark
   GEMINI_EMBEDDING_MODEL=models/text-embedding-004
   ```

## Usage

### Running Locally

Start the server using Uvicorn:
```bash
python3 -m uvicorn app.main:app --reload
```
The API will be available at `http://localhost:8000`.
Access the interactive docs at `http://localhost:8000/docs`.

### Running with Docker

Build and run the container:
```bash
docker build -t embedding-comparator .
docker run -p 8000:8000 --env-file .env embedding-comparator
```

## API Endpoints

### 1. Generate & Store Embeddings

**POST** `/api/v1/embeddings/openai`
Generate embeddings for a list of sentences using OpenAI and store them in Pinecone.

**Request:**
```json
{
  "sentences": [
    "The quick brown fox jumps over the lazy dog.",
    "Artificial Intelligence is transforming the world."
  ]
}
```

**POST** `/api/v1/embeddings/gemini`
Generate embeddings using Google Gemini and store them in Pinecone.

**Request:**
```json
{
  "sentences": [
    "The quick brown fox jumps over the lazy dog.",
    "Artificial Intelligence is transforming the world."
  ]
}
```

### 2. Semantic Search (Compare)

**POST** `/api/v1/compare`
Search for the most similar sentences in the database using a query text and a specific model.

**Request:**
```json
{
  "text": "Tell me about AI technology",
  "embed_type": "openai"  // or "gemini"
}
```

**Response:**
```json
{
  "query": "Tell me about AI technology",
  "embed_type": "openai",
  "results": {
    "matches": [
      {
        "id": "openai-uuid...",
        "score": 0.85,
        "metadata": { "text": "Artificial Intelligence is transforming the world." }
      }
    ]
  }
}
```

## Deployment on Render

1. Create a new **Web Service** on Render.
2. Connect this repository.
3. Choose **Docker** as the Runtime.
4. Add your Environment Variables in the Render Dashboard.
5. Deploy!
